# Stress Reduction with Music — Study Repository

This repository contains the experimental test code developed for the SJF-project **"Stress Reduction with Music"**, which was a group project for Swiss Youth in Science - TechXperience together with Selina Keller, Anastasia Flügge and Sofia Surace.

## Project Overview

This study investigated whether listening to music modulates physiological stress responses during acute stress induction and subsequent recovery. Two within-subject experiments utilized a computerized Stroop task to induce cognitive stress, monitoring participants' physiological responses through Heart Rate Variability (HRV via RMSSD) and subjective stress ratings. 

## Project Structure

In the Codebase is the Paper, data evaluation charts and the Python file that was used for gathering Data. In this group project an R-Script was used for the data evaluation. It is not contained for it was not any of my work.

The python file is loosely based on a program from Filippo Parisi and Gil Sharvit - working at iHomeLab at HSLU in Luzern. We adapted it for our purposes, simplifying and putting together a tailored test.

## Repository Contents

All files included in this repository represent the original code tests and analysis scripts used to process the unnormalized dataset for this study.
